# Controlled showcase audio notice

The files in this directory were produced from the fixed-rig Baby X and Baby Y
trial captures listed in `showcase-manifest.json`. The project created the
long-form showcase files by repeating the recorded 15-second sources. X7 also
contains two short quiet separators.

The repository owner instructed the project to publish its test audio for the
hackathon and confirmed that participant recordings could be publicly
distributed. This is a record of that instruction, not an independent audit of
the original upstream recording rights. The current repository does not record
an upstream URL, licence, or release for the Baby X and Baby Y source material.

These audio files are not covered by the project MIT licence. Do not reuse or
redistribute them outside this prototype without independently confirming the
source terms, consent scope, and any applicable withdrawal process.
